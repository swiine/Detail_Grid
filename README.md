# Detail_Grid

## Kobi Signs and Stripes

**Kobi Signs and Stripes** generates standard traffic signs and road markings
that follow either US or European rules.

### What it covers

- **Traffic signage**: regulatory, warning and guide signs.
- **Road markings**: lane lines, edge lines, stop and yield lines, crosswalks,
  arrows and other pavement markings.

### Supported standards

| Region | Standard |
| ------ | -------- |
| United States | [MUTCD](https://mutcd.fhwa.dot.gov/) (Manual on Uniform Traffic Control Devices) |
| Europe | European rules based on the [Vienna Convention on Road Signs and Signals](https://unece.org/transport/road-traffic-and-road-signs-and-signals-agreements-and-conventions) |

You pick the rule set, and Kobi Signs and Stripes produces signs and markings
with the shapes, colors and layouts that rule set requires.
