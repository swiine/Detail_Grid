LISTBLOCKS - list every block in a drawing

1. In AutoCAD type APPLOAD, pick ListBlocks.lsp, click Load
   (or drag the file into the drawing).
2. Type LISTBLOCKS.

Shows every block, how many times it is used, and xrefs separately.
Saves <drawing>_Blocks.txt next to the drawing and opens it in Notepad.
The bottom line is ready to paste into BS-DELETE / BS-COPY in BlockSwap.scr.
