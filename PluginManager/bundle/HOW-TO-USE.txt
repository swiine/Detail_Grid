PluginManager for AutoCAD 2025 / 2026
=====================================

INSTALL
  1. Close AutoCAD.
  2. Double-click install.bat.
  3. Start AutoCAD. PluginManager now loads automatically every time.
     (If AutoCAD asks whether to load it, choose "Always Load".)

COMMANDS (type in AutoCAD)
  PMLOAD     Pick a plugin .dll and load it. Load your plugins this way, not with NETLOAD.
  PMUNLOAD   Unload a plugin loaded with PMLOAD.
  PMRELOAD   Reload from disk after you rebuild it (Enter = all).
  PMDISABLE  Switch off any plugin .dll, including ones loaded with NETLOAD or at startup.
  PMENABLE   Turn a disabled plugin back on.
  PMLIST     Show what is loaded and disabled.

NOTES
  - Plugins loaded with PMLOAD can be fully unloaded, and their .dll files are not
    locked, so you can rebuild them while AutoCAD is open.
  - Plugins loaded any other way can only be disabled (their commands stop working).
    They stay in memory until AutoCAD closes.
  - Disabling lasts until AutoCAD closes.

UNINSTALL
  Close AutoCAD and double-click uninstall.bat.
